# nixos-configurations

One flake for all my NixOS machines (nixos-unstable, KDE Plasma, no Home Manager).

| Host     | Machine                               |
| -------- | ------------------------------------- |
| `laptop` | ThinkPad T480s                        |
| `pc`     | Ryzen 7 7700X, Radeon RX 6950 XT      |

```
flake.nix          inputs and nixosConfigurations.<host>
modules/           shared settings, imported by every host
  nix.nix            nix daemon, flakes, gc, optimise
  base.nix           boot, firmware, network, locale, audio, CLI tools
  users.nix          user account
  unfree.nix         unfree packages allowed by name
  plasma.nix         my.desktop.plasma.enable
  apps.nix           my.apps.enable (desktop apps, Steam)
  dev.nix            my.dev.enable (VS Code, Java, Go, Rust)
  printing.nix       my.printing.enable (CUPS, Avahi, SANE)
hosts/<host>/      machine-specific settings only
  default.nix
  hardware-configuration.nix   generated by nixos-generate-config
checks/            flake checks run by `nix flake check`
scripts/           check, find-module, nixpkgs-path, nixos-mcp
CLAUDE.md, .claude/  rules and tooling for Claude Code
.mcp.json          mcp-nixos MCP server for Claude Code (third-party)
```

Install: see [INSTALL.md](INSTALL.md). Rebuild: `sudo nixos-rebuild switch --flake .#<host>`.

## Checks

`scripts/check` runs everything CI runs on each push and pull request:

- formatting (`nix fmt`)
- full evaluation of every host, failing on any evaluation warning
- no NixOS module warnings (renamed or removed options)
- no package listed in `environment.systemPackages` or
  `users.users.<name>.packages` that has a `programs.*`/`services.*` module,
  and every listed package carries a `# no NixOS module` comment
- no untracked `.nix` files (the flake can't see them)

`scripts/find-module <name>` shows whether nixpkgs has a module for a program.
`scripts/nixos-mcp '<json>'` asks the mcp-nixos server (search.nixos.org
index) from the command line.
